# ANCOS NEURO self-evolution baseline

Evolution, skills, and methods subsystems exist in source. This audit does not establish a live loop that autonomously proposes, evaluates, promotes, and safely rolls back a capability change. Cognitive-fabric skill/evolution loop tests failed, and the Phase 5 method/meta-learning group has outstanding failures.

Required promotion lifecycle:

1. Preserve proposal source, task evidence, model/config version, and evaluation dataset provenance.
2. Evaluate in an isolated environment against a fixed baseline; include regressions, security boundaries, cost, and uncertainty.
3. Keep newly created skills/methods unverified until independent empirical tests and reviewer receipts pass.
4. Require policy/owner approval for production-impacting promotion.
5. Canary with bounded scope, maintain rollback artifact, and audit every transition.

Until those receipts exist, evolution status is `NOT_ACCEPTED`; no self-modification capability is inferred from module presence.
